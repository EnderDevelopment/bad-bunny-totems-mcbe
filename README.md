# Bad Bunny Totems

Bad Bunny Totems is a Minecraft Bedrock Edition add-on that modifies the totem of undying to feature Bad Bunny's face with 4 different pixel art designs. When the totem is activated to save the player from death, it plays a short musical fragment from a Bad Bunny song, if provided. If no audio is available, it plays an original reggae sound inspired by urban music. The add-on includes particles, flashes, and visual effects upon activation. The sound plays only once per activation. The add-on is compatible with Minecraft Bedrock Edition and preserves the totem's original functionality.

## Install

1. Download the `.mcaddon` file from the GitHub repository.
2. Open Minecraft Bedrock Edition.
3. Go to the "Add-Ons" section in the settings.
4. Click on "Add" and select the downloaded `.mcaddon` file.
5. Enable the add-on and start a new world or reload an existing one.

## Use

1. Craft the totem of undying as usual.
2. Hold the totem in your hand.
3. When you are about to die, activate the totem by right-clicking.
4. The totem will activate, playing a musical fragment and displaying visual effects.
